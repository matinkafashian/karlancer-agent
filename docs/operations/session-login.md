# ورود اولیه و بازیابی نشست کارلنسر

1. فقط یک worker باید به volume پروفایل مرورگر دسترسی نوشتن داشته باشد.
2. نمایش noVNC را عمومی نکنید؛ با SSH tunnel به آن وصل شوید.
3. داخل container متصل به نمایش، `scripts/login-session.sh` را اجرا کنید.
4. ورود و در صورت نیاز 2FA را شخصاً در مرورگر انجام دهید؛ رمز و کد ورود در فایل یا دیتابیس ذخیره نمی‌شود.
5. اسکریپت را با `Ctrl+C` ببندید تا Chromium تمیز بسته و پروفایل flush شود.
6. worker عادی را بالا بیاورید و health check نشست را بررسی کنید.

اگر وضعیت `expired`، `challenge` یا `unknown` شد، ارسال متوقف می‌ماند. worker را متوقف کنید، مراحل بالا را دوباره انجام دهید و CAPTCHA را فقط دستی حل کنید. پروفایل، cookie یا session storage نباید وارد Git، image یا log شود.
